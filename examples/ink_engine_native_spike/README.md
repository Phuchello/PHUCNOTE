# Isolated AndroidX Ink spike

Separate native Android package `com.phucnote.ink_spike`; no Flutter editor,
PHUCNOTE notes/settings or `.bfly` dependency. Stable AndroidX Ink 1.0.0 and
motionprediction 1.0.0 are pinned. Uses existing root Gradle wrapper, AGP 9.1,
JDK 17 and Android SDK 36; minimum Android API 23. No SDK installation needed.

From repository root, set JAVA_HOME, ANDROID_HOME/ANDROID_SDK_ROOT and
GRADLE_USER_HOME to the existing `scratch/toolchain` paths, then run:

```powershell
./tool/ink_benchmark/run_native_spike.ps1
```

The runner builds/installs only this package, assigns a fresh run ID, waits for
actual smoke results, backgrounds/resumes it and saves JSON/screenshot/memory
under `artifacts/ink-engine/`. `-SkipBuild` uses the existing APK. `-SmokeOnly`
reuses the private previous geometry measurements; it requires a prior complete
run and is explicitly tagged in JSON. It never resets or deletes user data.

`ink_traces.json` is generated by `tool/ink_benchmark/traces.dart`; root focused
tests assert it matches the current catalog. Synthetic events carry historical
samples and optional provisional predictions. The finished listener commits dry
strokes and removes wet strokes in the same UI run loop. Direct authoring
cancellation must not create a completed stroke; idle pause/resume must retain
the one completed stroke. Cancellation uses the initiating DOWN event directly,
not dispatch through ACTION_CANCEL. FLAG_CANCELED, multitouch ownership and
backgrounding during active ink are unvalidated; ACTION_UP currently ignores
FLAG_CANCELED. This is not production input/lifecycle acceptance.

Smoke PASS is separate from **exactInputFidelity FAIL**: small native coordinate
differences were measured. Original fixture coordinates remain canonical. No
native serialization or `.bfly` transfer is attempted. Native debug CPU numbers,
raw window metrics and ART/native-heap snapshots cannot rank this engine against
Flutter profile mode or prove Y700 latency/quality. See root audit/results/plan.
